# Codex Feature Brief — Read Before GitHub/Task Work

The latest ZIP is the current 100% codebase. Previous Codex context covers only ~40%; later work covers ~60%. Preserve current functionality.

Priority feature work:

1. **Builder DNA** — evolve the existing GitHub integration into a Cadens-native proof-of-work and builder compatibility experience. Do not clone GitHub UI or terminology. See `guides/GITHUB_AND_TASKS_INNOVATION_PLAN.md`.
2. **Daily Flow** — evolve Tasks into a calm daily execution cockpit inspired by useful task-management patterns: Now, Today, planned execution, deadline, effort, checklist progress, My Day, history and reminders. Do not clone the reference site's visual design or copy.
3. **Build → Plan → Reflect** — connect Builder DNA, Tasks/Plan and Journal/Daybook into a single Cadens workflow.

Definition of success: the user feels Cadens helps them decide what matters, execute it, reflect on progress and connect with compatible builders. It must not feel like GitHub with a task list attached.
